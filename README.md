# FrameLab — Responsive Product Landing Page

FrameLab is a fictional online learning platform that helps aspiring UI/UX designers learn Figma through practical projects, guided lessons, and mentor feedback.

## Target Audience

- Students beginning their UI/UX design journey
- Aspiring designers learning Figma
- Learners who want to create portfolio-ready case studies
- Career changers looking for project-based design experience

## Project Overview

This project was created as a responsive product landing page. It presents FrameLab’s learning experience, project-based curriculum, community, and primary call to action.

The page includes:

- A responsive header with a logo, navigation links, CTA, and mobile menu
- A hero section with a headline, description, buttons, and original product illustration
- Three feature cards
- A featured project section
- A community call-to-action section
- A responsive multi-column footer

## Reusable Components

The interface uses reusable patterns for:

1. **Buttons** — primary and secondary CTA styles
2. **Feature cards** — shared layout with an icon, number, title, and description
3. **Icons** — a reusable SVG icon component
4. **Navigation links** — shared desktop and mobile navigation data
5. **Typography labels** — reusable eyebrow labels for section headings

## Design Choices

### Colors

- **Cream (`#FFF8E8`)** — creates a warm and welcoming background
- **Coral (`#F65F4D`)** — highlights important actions and key content
- **Ink (`#171B1C`)** — provides strong contrast and readability
- **Yellow (`#FFD45C`)** — adds energy and creativity
- **Mint (`#91D9C8`)** — communicates progress and positive feedback

### Typography

- **Manrope** is used for bold headings and strong visual hierarchy.
- **DM Sans** is used for body copy, navigation, and interface labels.

### Visual Direction

The design uses rounded cards, bold typography, generous spacing, and playful accent colors. This makes the platform feel creative and approachable while keeping the content easy to scan. The original dashboard illustration reinforces the project-based learning concept.

## Responsiveness

The layout adapts across desktop, tablet, and mobile screens. Navigation collapses into a mobile menu, content grids stack vertically, and typography and spacing scale for smaller displays.

## Technology

- React 19
- TypeScript
- Vite
- Tailwind CSS v4

## Run Locally

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```

Create a production build:

```bash
pnpm build
```
